Self-Hosted Convex Backend & Dashboard

easyCV runs the official open-source self-hosted Convex backend (ghcr.io/get-convex/convex-backend:latest) and Convex Dashboard (ghcr.io/get-convex/convex-dashboard:latest).

Port 3210

Convex Client API

Real-time WebSocket & HTTP RPC queries/mutations.

Port 3211

Convex Site & HTTP Actions

Stripe webhooks, file downloads, and public handlers.

Port 6791

Convex Admin Dashboard

Interactive table viewer, schema manager, and function logs.

# Retrieve self-hosted Convex Admin Key from running pod

kubectl exec deploy/convex-backend -n easycv -- ./generate_admin_key.sh

Dual Database Persistence: SQLite vs. PostgreSQL

Option 1: SQLite with PersistentVolume (Default)

Zero configuration. Backed by Kubernetes convex-data-pvc on Vultr Block Storage. Suitable for staging, local testing, and standard demo environments.

Option 2: Vultr Managed PostgreSQL

Production HA database. Set POSTGRES_URL=postgres://... in .env.production. Convex detects it automatically and activates the postgres-v5 engine driver.

Autonomous Vultr Kubernetes Deployment

# 1-Command Autonomous Deployment to VKE

./deploy.sh

The deployment script automatically builds linux/amd64 images, pushes to Vultr Container Registry (VCR), provisions pods and storage, generates admin keys, and deploys the Convex schema with zero manual intervention.

GitHub & GitLab CI/CD Mirroring

easyCV features dual-platform CI/CD integration:

  • GitHub Actions (.github/workflows/deploy.yml): Multi-arch Docker buildx, VCR push, and Kubernetes rollout.
  • GitLab CI (.gitlab-ci.yml): Full test and deployment pipeline for GitLab instances and mirrored repositories.
  • GitHub Pages (.github/workflows/docs.yml): Automated build and publish of this developer documentation site to gh-pages.
